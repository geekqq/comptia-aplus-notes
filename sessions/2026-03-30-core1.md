### 错题 1 — 移动设备麦克风清洁

**题目：** Which item is NOT recommended for clearing blockages from a mobile device microphone?

|  |  |
| --- | --- |
| ❌ 我的答案 | Soft brush（软毛刷） |
| ✅ 正确答案 | Can of compressed air（压缩空气罐） |

**知识点解析**

压缩空气罐的高压气流会损坏麦克风内部振膜（diaphragm）。安全工具：Soft brush、Lint-free cloth、Microfiber cloth。

**🔑 记忆口诀：** 麦克风怕气压，压缩空气别乱喷。

### 错题 3 — NFC 的功能

**题目：** NFC enables: (Select all that apply)

|  |  |
| --- | --- |
| ❌ 我的答案 | Contactless payment ✅、Access control ✅、Wireless charging ❌；漏选了 Device pairing and data exchange |
| ✅ 正确答案 | Contactless payment、Device pairing and data exchange、Access control |

**知识点解析**

NFC 特性：13.56 MHz，有效距离约 4cm。支持：非接触支付、设备配对/数据交换、门禁控制。❌ 无线充电 = Qi 标准（电磁感应），与 NFC 无关。

**🔑 记忆口诀：** NFC = 近场短距，充电是 Qi 的事，别混淆。

### 重点知识笔记 — S.M.A.R.T. 与存储监控工具

**题目：** Which tool can be used to monitor the health and performance of a laptop's storage drive?（答对，作为知识点笔记）

✅ 正确答案：**S.M.A.R.T.**

| 工具 | 实际用途 | 能监控健康？ |
| --- | --- | --- |

| chkdsk | 检查并修复文件系统错误 | ❌ |
| Disk Defragmenter | 整理磁盘碎片（仅 HDD 有效） | ❌ |

**🔑 记忆口诀：** S.M.A.R.T. = 硬盘自己的体检报告；chkdsk = 外科手术；Storage Sense = 打扫卫生；碎片整理 = 整理房间。

### 错题 8 — 移动设备蓝牙模块

**题目：** Which statement regarding a mobile device Bluetooth module is true?

|  |  |
| --- | --- |
| ❌ 我的答案 | Bluetooth modules are typically located near the device's display and require screen removal |
| ✅ 正确答案 | Bluetooth is usually integrated into the Wi-Fi card or directly into the motherboard |

**知识点解析**

蓝牙模块通常以两种形式存在：① Wi-Fi/蓝牙二合一 Combo Card ② 直接焊接在主板上。更换后需重新手动配对，不会自动恢复。不同品牌/型号之间有兼容性要求，不能随意替换。

**🔑 记忆口诀：** 蓝牙和 Wi-Fi 住一起（Combo Card），换了要重新配对。

### 错题 11 — Docking Station 特征（选3）

**题目：** Docking stations: (Select 3 answers)

| 选项 | 正确？ | 我的选择 |
| --- | --- | --- |
| Feature a compact and lightweight design | ❌ 错误选项 | ❌ 错选了 |
| Are often designed for specific brands/models | ✅ 正确 | ❌ 漏选 |
| Provide additional hardware capabilities (graphics, storage) | ✅ 正确 | ✅ |
| Tend to be larger and less portable, for fixed workspaces | ✅ 正确 | ✅ |

**知识点解析**

Docking Station 三大特征：① 品牌/型号专属 ② 增强硬件能力（外接显卡/存储）③ 体积较大，固定使用。"紧凑轻便"是 USB Hub / Port Replicator 的特征，不是 Docking Station。

| 对比 | Docking Station | USB Hub / Port Replicator |
| --- | --- | --- |
| 体积 | 较大，固定 | 小巧便携 |
| 兼容性 | 品牌专属 | 广泛兼容 |
| 功能 | 接口扩展 + 硬件增强 | 仅接口扩展 |

**🔑 记忆口诀：** Docking = 大型专属停靠站；Hub = 小巧万能插线板。

### 错题 12 — 传统 SIM 卡特征（NOT 题）

**题目：** Which statement does NOT refer to the characteristic features of a traditional SIM?

|  |  |
| --- | --- |
| ❌ 我的答案 | Requires physical SIM swap for changing carriers |
| ✅ 正确答案 | None of the above（以上都不是） |

**知识点解析**

这是"NOT 题"陷阱！正确答案 None of the above = 列出的所有选项都是传统 SIM 的特征，没有一项"不属于"传统 SIM。

| 选项 | 是传统 SIM 的特征？ |
| --- | --- |
| Physical card（实体卡） | ✅ |
| Installed by inserting into SIM slot | ✅ |
| Can be moved between devices | ✅ |
| Requires physical SIM swap for changing carriers | ✅ 也是！换运营商就是要物理换卡 |

陷阱："需要物理换卡换运营商"恰恰是传统 SIM 的特征（eSIM 才不需要换卡）。

**🔑 记忆口诀：** 传统 SIM 四大特点全是它的特征，None of above = 四个都对。

### 错题 13 — eSIM 判断题

**题目：** An eSIM is a modern alternative to the traditional SIM card. Unlike traditional SIMs, an eSIM is an embedded chip built into the device (not a physical card). — True or False?

|  |  |
| --- | --- |
| ❌ 我的答案 | False |
| ✅ 正确答案 | True |

**知识点解析**

| 对比项 | 传统 SIM | eSIM |
| --- | --- | --- |
| 形态 | 物理卡（可拔插） | 嵌入式芯片（焊接在主板） |
| 换运营商 | 需要物理换卡 | 远程配置，无需换卡 |
| 设备移动 | 可在多台设备间移动 | 绑定设备，不可移动 |
| 常见设备 | 大多数手机 | iPhone XS+、Apple Watch、部分笔记本 |

**🔑 记忆口诀：** eSIM = embedded SIM，嵌在里面出不来，换运营商靠远程。

### 错题 14 — 移动设备部署模式

**题目：** Which mobile device deployment model allows organizations to provide and own the devices while permitting personal use?

|  |  |
| --- | --- |
| ❌ 我的答案 | CYOD（Choose Your Own Device） |
| ✅ 正确答案 | COPE（Corporate-Owned, Personally-Enabled） |

**知识点解析**

四大移动设备部署模式对比：

| 缩写 | 全称 | 谁拥有设备？ | 允许个人使用？ | 关键特征 |
| --- | --- | --- | --- | --- |
| **BYOD** | Bring Your Own Device | 员工 | ✅ 本来就是个人设备 | 员工自带设备上班，公司管理工作部分 |
| **COPE** | Corporate-Owned, Personally-Enabled | 公司 ✅ | ✅ 允许 | **公司买单、公司持有，但允许员工个人使用** ← 本题答案 |
| **CYOD** | Choose Your Own Device | 可以是公司或员工 | 视政策而定 | 员工从公司批准的设备列表中自选型号 |
| **COBO** | Corporate-Owned, Business-Only | 公司 | ❌ 不允许 | 纯商用设备，只能用于工作，无个人使用权 |
| **ZTA** | Zero Trust Architecture | — | — | 这是安全框架，不是设备部署模式！ |

题目关键信息："organizations provide and own"（公司提供并持有）+ "permitting personal use"（允许个人使用）= **COPE**。

CYOD 的重点是"员工选择设备型号"，不强调"公司持有 + 个人使用"这个组合。

**🔑 记忆口诀：**

- BYOD = Bring（自带）
- COPE = Corporate + Personal（公司设备，个人可用）
- CYOD = Choose（自选型号）
- COBO = Business Only（纯商用）

### 错题 15 — MDM 远程管理下应用消失的原因

**题目：** A critical business app is no longer appearing on a user's company-issued smartphone, while colleagues still have it. What is the most likely cause to investigate first?

|  |  |
| --- | --- |
| ❌ 我的答案 | The user accidentally deleted the application icon from their home screen |
| ✅ 正确答案 | The application may have been remotely uninstalled, or the user's access may have been revoked |

**知识点解析**

这道题的关键背景是：**公司发放的设备（company-issued）**，说明设备受 MDM（Mobile Device Management，移动设备管理）系统管控。

为什么正确答案是远程卸载/访问权限撤销？

- 公司设备通过 MDM 集中管理，IT 管理员可以远程推送/删除应用
- "其他同事还有这个应用"说明不是系统故障，而是针对该用户的管理操作
- 企业应用通常受保护，用户无法随意从主屏幕删除（且删除图标不等于删除应用）

为什么"误删图标"是错的？

- 从主屏幕移除图标 ≠ 卸载应用，应用仍可在应用列表中找到
- 在受 MDM 管理的设备上，用户通常没有权限卸载企业应用
- 题目说"不再出现"，更符合被彻底移除或权限撤销的场景

**MDM 常见功能（考试高频）：**

- 远程安装/卸载应用
- 远程锁定/抹除设备
- 强制执行安全策略（密码强度、加密）
- 追踪设备位置
- 撤销特定用户的应用访问权限

**🔑 记忆口诀：** 公司设备 = MDM 管着，应用消失先查管理员操作（远程卸载/权限撤销），别先怪用户误操作。
